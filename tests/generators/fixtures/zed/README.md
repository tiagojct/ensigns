# Zed theme schema fixture

theme.schema.json is an unmodified copy of https://zed.dev/schema/themes/v0.2.0.json, retrieved on 2026-10-03. It describes the ThemeFamilyContent interface generated by Zed's theme crate. The upstream crate declares GPL-3.0-or-later; its licence text is copied here as LICENSE-GPL from https://github.com/zed-industries/zed/blob/main/LICENSE-GPL.

This fixture is used only by tests/generators/editors.test.ts for offline output validation. It is not imported by the generators or copied into exports, packages or preview pages. The test also checks style property names because the upstream schema allows unknown properties.
